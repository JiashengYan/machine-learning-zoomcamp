# 线性回归

本节介绍线性回归，它用于解决回归问题，即预测数值的问题，例如汽车价格。我们将推导公式，用 Python 为一辆汽车实现预测，并了解预测值由哪些部分组成。

## 一辆汽车的预测公式

线性回归是解决回归问题的模型。回顾导论：机器学习任务包括回归、分类和排序。回归意味着预测数字，模型输出是一个数值，本例中就是汽车价格。

你可能还记得导论中的这个公式：

```text
g(X) ≈ y
```

这里 g 是模型，X 是特征矩阵，y 是目标，也就是价格。模型 g 将采用线性回归。

在讨论矩阵形式之前，先简化问题：不看整个特征矩阵，只看一个观测样本。一个样本就是一辆汽车，以及它的价格：

一辆汽车对应特征矩阵中的一行，因此可视为一个含 n 个元素的向量：第一个特征是 x<sub>i1</sub>，然后是 x<sub>i2</sub>，直到 x<sub>in</sub>。我们希望找到一个函数，接收所有这些特征，输出接近实际价格的数值：

```text
g(xi) ≈ yi
```

从训练集中取一个例子。注意，这里只看训练集，不查看验证集或测试集。取第 10 行：这是一辆 2015 年生产的 Rolls-Royce Phantom Drophead Coupe，拥有许多特征。我们只选三项：发动机马力、城市路况下每加仑行驶英里数，以及受欢迎程度：


这辆汽车的特征向量为：

```python
xi = [453, 11, 86]
```

这里 i 为 10，特征分别是发动机马力（453）、城市路况下每加仑行驶英里数（11）和受欢迎程度（86）。受欢迎程度指汽车在 Twitter 上被提及的次数。现在需要一个函数，接收这个 xi 并为该汽车生成预测。

## 线性回归公式

我们需要组合这些数值，使结果接近价格。线性回归的公式如下：

$$g(x_i) = w_0 + w_1 \cdot x_{i1} + w_2 \cdot x_{i2} + w_3 \cdot x_{i3}$$

首先是偏置项 w<sub>0</sub>，表示在完全不了解汽车时给出的预测。但我们确实掌握了一些信息，所以每个特征都乘以对应权重：马力对应 w<sub>1</sub>，每加仑行驶英里数对应 w<sub>2</sub>，受欢迎程度对应 w<sub>3</sub>。

特征部分是一个求和表达式，因此可以写得更紧凑。因为 i 已用来表示汽车，我们用 j 表示特征，取值从 1 到 n，本例中 n 为 3：

$$g(x_i) = w_0 + \sum_{j=1}^{n} w_j \cdot x_{ij}$$

## 用 Python 实现

开始实现。我们有特征向量 xi、偏置项 w0，以及为每个特征提供一个权重的向量 w：

```python
xi = [453, 11, 86]
w0 = 7.17
w = [0.01, 0.04, 0.002]
```

稍后再讨论这些权重从何而来，目前先自行设定。函数将预测初始化为 w0，然后对每个特征，加上该特征与其权重的乘积：

```python
def linear_regression(xi):
    n = len(xi)

    pred = w0

    for j in range(n):
        pred = pred + w[j] * xi[j]

    return pred
```

公式中的求和从 1 到 n，但 Python 的索引从 0 开始，因此循环从 0 到 n-1。这就是整个实现：对特征向量的每个元素，将 w<sub>j</sub> 与 x<sub>ij</sub> 的乘积累加起来。


## 预测值的组成

将它应用于这辆汽车：

```python
linear_regression(xi)
```

```
12.312
```

为了理解这个数字，查看它由哪些部分组成：

```text
7.17 + 453·0.01 + 11·0.04 + 86·0.002 = 12.312
```

- 首先是偏置项 7.17，表示在不知道任何信息时对普通汽车给出的预测。
- 这辆汽车有 453 马力。每增加一马力，预测值增加 0.01：一马力对应增加 0.01，100 马力对应增加 1。发动机马力越大，汽车价格越高，这符合直觉。
- 下一项是城市路况下每加仑行驶英里数，权重为 0.04。汽车在城市中的油耗越高，价格越贵。这可能有一定道理：耗油更多的汽车可能更豪华。
- 最后一项是受欢迎程度，即 Twitter 上的提及次数，权重较小，为 0.002。它对价格的影响似乎不大，需要很多人提及一辆汽车，这一项才会产生明显影响。

## 从对数价格还原为美元

预测值 12.312 并不是以美元表示的价格。由于价格分布存在长尾，我们对 y 应用了 log1p 变换，所以模型预测的是价格的对数。要撤销对数变换，需要使用指数函数。NumPy 提供了相应函数：

```python
np.expm1(12.312)
```

```
222347.2221101062
```

因此，我们对这辆汽车的预测约为 222,000 美元。还有一个快捷函数：`np.expm1` 是 `np.log1p` 的逆函数，先后应用二者，就能回到原始值：

```python
np.log1p(222347.2221101062)
```

```
12.312
```


这就是单辆汽车的线性回归：我们在一个三维的小特征向量上实现了公式。下一节将推广为同时处理所有汽车的[向量形式](06-linear-regression-vector_chi.md)。

## 笔记

线性回归用于解决回归任务，目标是拟合数据，并对新样本进行预测。模型输入是**特征矩阵** `X`，输出是 `y` 的**预测向量**，尽可能接近**真实** `y`。线性回归公式由偏置项 \( $w_0$ \) 和各特征与对应权重的乘积之和组成，即 \( $x_{i1} \cdot w_1 + x_{i2} \cdot w_2 + ... + x_{in} \cdot w_n$ \)。偏置项表示没有其他信息时的预测。

简单的线性回归公式如下：

$g(x_i) = w_0 + x_{i1} \cdot w_1 + x_{i2} \cdot w_2 + ... + x_{in} \cdot w_n$.

还可以进一步简化为：

$g(x_i) = w_0 + \displaystyle\sum_{j=1}^{n} w_j \cdot x_{ij}$

下面是用 Python 实现线性回归的简单示例：

~~~~python
w0 = 7.1
def linear_regression(xi):
    
    n = len(xi)
    
    pred = w0
    w = [0.01, 0.04, 0.002]
    for j in range(n):
        pred = pred + w[j] * xi[j]
    return pred
~~~~
        

观察上述方程中的 $\displaystyle\sum_{j=1}^{n} w_j \cdot x_{ij}$，可以发现它就是向量之间的点积。因此，方程可以改写为 $g(x_i) = w_0 + x_i^T \cdot w$。

需要通过逆变换函数 `exp()` 将结果还原到原始尺度。
