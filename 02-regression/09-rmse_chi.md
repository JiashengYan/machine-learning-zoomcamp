# 均方根误差（RMSE）

上一节训练了第一个模型，并将预测值与真实值绘图比较。直方图显示预测有一定偏差，但图表并不是客观指标。本节学习量化回归模型好坏的一种方法：均方根误差，简称 RMSE。

## 公式

RMSE 从预测值与真实值的差开始。对于每个观测样本 `i`，`g(xi)` 是预测值，`yi` 是真实值。先计算差值并平方，再对全部 `m` 个样本的平方差求平均，最后开平方：

```text
RMSE = sqrt( (1/m) · Σ (g(xi) - yi)² )
```

下面用一个小例子拆解各个步骤。

## 计算示例

假设有四个观测样本。以下分别是预测值和实际价格：

```text
y_pred:  10     9     11    10
y:        9     9     10.5  11.5
```

第一步，计算每个预测值与对应真实值的差：

```text
10 - 9    =  1
 9 - 9    =  0
11 - 10.5 =  0.5
10 - 11.5 = -1.5
```

接着，将每个差值平方：

```text
1   → 1
0   → 0
0.5 → 0.25
-1.5 → 2.25
```

平方有两个作用：使正负误差可以统一比较，避免相互抵消；同时对较大的误差施加更大的惩罚。

然后计算平方误差的平均值：

```text
(1 + 0 + 0.25 + 2.25) / 4 = 0.875
```

这就是均方误差（MSE）。本例的均方误差为 0.875：

最后一步是开平方：

```text
sqrt(0.875) ≈ 0.93
```

开平方使误差恢复为与目标变量相同的单位。对于这四个样本，均方根误差约为 0.93。

## 实现

现在用 NumPy 实现。函数接收真实值向量和预测值向量：

```python
def rmse(y, y_pred):
    error = y - y_pred
    se = error ** 2
    mse = se.mean()
    return np.sqrt(mse)
```

首先计算误差，即 `y` 与 `y_pred` 的差，再平方。求平均时无须手动求和并除以元素数量，因为 NumPy 的 `mean` 方法可以直接得到均方误差。最后开平方并返回结果。

可以直接在表达式中对差值平方，使函数稍微简化：

```python
def rmse(y, y_pred):
    se = (y - y_pred) ** 2
    mse = se.mean()
    return np.sqrt(mse)
```

现在用它评估基准模型。我们已经有训练集上的预测值 `y_pred`：

```python
rmse(y_train, y_pred)
```

```text
0.7554192603920132
```


基准模型的 RMSE 约为 0.76。与图表相比，单个数值更便于使用：每当添加特征、变换变量或尝试不同模型后，都重新计算它。如果数值下降，说明模型有所改善。

## 笔记

* 上一节发现训练集中的预测值与真实目标值存在偏差。需要一种量化模型好坏的方法，RMSE 可以帮助我们。
* 均方根误差（RMSE）用于评估回归模型，衡量模型的预测误差。这个数值可用于比较模型，帮助选择预测效果最好的模型。

$$RMSE = \sqrt{ \frac{1}{m} \sum_{i=1}^{m} {(g(x_i) - y_i)^2}}$$

- $g(x_i)$ 是预测值
- $y_i$ 是真实值
- $m$ 是数据集中的观测样本数量，也就是汽车数量
