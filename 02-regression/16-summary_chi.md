# 汽车价格预测项目总结

这是第二部分的最后一节课程，下面总结所学内容。整个部分围绕一个项目展开：预测汽车价格。再回顾一次，看看各个环节如何衔接。

## 项目

下载了包含价格和各种汽车特征的数据集，例如品牌、车型、发动机燃料类型、变速箱类型等。我们要预测的目标变量是价格 MSRP，即制造商建议零售价。

## 数据准备与探索性数据分析

首先清理并准备数据，使格式统一。列名和字符串值中存在空格、大小写不一致的问题，因此全部转为小写，并用下划线替换空格，数据变得更整洁。


随后进行探索性数据分析。发现价格分布存在长尾，通过对数变换减弱了长尾的影响。这是个有用的做法，因为长尾分布通常会给机器学习模型带来问题，变换后的分布更接近钟形曲线。

还发现数据集中存在缺失值，而当前模型训练前必须处理缺失值。因此决定简单地用零替换它们。

## 验证框架

接着建立验证框架，将数据划分为训练集、验证集和测试集。这是最有用的步骤之一，帮助我们尽早发现模型的问题。

## 线性回归与正规方程

然后学习线性回归的工作方式。先针对单个样本，用简单公式和 for 循环实现；再通过点积扩展为向量形式，最终推广到矩阵形式，也就是矩阵与向量的乘法。模型训练得到的参数是权重向量，包括偏置项和特征权重。



随后学习如何真正获得这些权重，也就是如何训练模型。机器学习并非魔法，这里只是一个名为正规方程的公式。用 NumPy 实现该公式，并训练第一个模型——仅使用五个基础数值特征的基准模型。



从图中可以看到，基准模型的表现不太好。但仅凭图表判断模型性能并不客观，因此介绍了均方根误差 RMSE，用于评估回归模型的质量。

编写的 `prepare_X` 函数使训练集和验证集能够使用相同方式准备特征矩阵，从而加快实验。在整个部分中，我们不断重新定义这个函数，再复用相同的验证单元格。

## 特征工程与类别变量

之后进行简单的特征工程，从现有特征创建新特征。创建了车龄特征后，模型表现明显改善：预测分布与真实值分布比之前更加吻合。


随后学习如何整合类别变量，用一组二元列表示每个类别变量。这种方法叫独热编码，下一部分讲分类时会进一步介绍。


加入所有类别特征后，模型性能显著下降，RMSE 突然变得很大。幸好有验证框架，很容易发现问题。原因是数值不稳定。为解决它，采用正则化：在对矩阵 X 转置乘 X 求逆之前，给其对角线加上一个小数。这有效改善了问题，包含所有类别特征的模型也比之前版本表现更好。

整个项目可以概括为：

- EDA：观察数据，查找缺失值
- 目标变量分布：存在长尾，因此应用对数变换
- 验证框架：划分训练集、验证集和测试集，帮助发现问题
- 正规方程：依靠数学求解
- 用 NumPy 实现
- 用 RMSE 验证模型
- 特征工程：车龄、类别特征
- 正则化：处理数值不稳定问题

## 调优与最终模型

引入正则化后，尝试不同的正则化参数值，寻找最佳选择。认为 0.001 是不错的取值，即使未必是绝对最优，也与其他候选值相近，因此采用它。

随后训练最终模型：将训练集和验证集合并，再用方便的 `prepare_X` 准备数据并训练。还学习了如何对未知价格的汽车进行预测。实际上，这辆汽车来自测试集，我们知道其真实价格，只是假装不知道；最终预测与实际价格相差不算太大。
