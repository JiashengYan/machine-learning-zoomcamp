# 正则化

[上一节](12-categorical-variables_chi.md)添加类别变量后，模型的 RMSE 达到 41，权重也变得非常大。本节分析原因，并学习处理这种问题的技术：正则化。

## 并不总是存在的逆矩阵

回顾用于训练模型的正规方程：

```
w = (XᵀX)⁻¹ Xᵀ y
```

问题出在求逆这一步：需要对格拉姆矩阵 `XᵀX` 求逆，但有时逆矩阵不存在。

当特征矩阵 X 存在重复列时，就会出现这种情况。用一个小矩阵快速验证，其中第二列和第三列完全相同：

```python
X = [
    [4, 4, 4],
    [3, 5, 5],
    [5, 1, 1],
    [5, 4, 4],
    [7, 5, 5],
    [4, 5, 5],
]
```

计算格拉姆矩阵后，可以看到它也有重复列，第二列和第三列相同：


这种情况下，逆矩阵不存在。在线性代数中，我们说某列是其他列的线性组合；本例中，就是第三列与第二列重复。

## 带噪声的数据使逆矩阵数值巨大

汽车价格问题中并未直接出现奇异矩阵错误，因此情况并不完全相同。原因是实际数据通常不完全干净：记录观测值时可能有误差，例如本应记录 5，却记录成 5.00000001。

给矩阵中的一个值加上这样一个极小的数：

```python
X = [
    [4, 4, 4],
    [3, 5, 5],
    [5, 1, 1],
    [5, 4, 4],
    [7, 5, 5],
    [4, 5, 5.00000001],
]
```

现在两列不再完全相同，而是略有差异，所以矩阵不再严格奇异。至少在数值计算中，NumPy 能找到一个逆矩阵。但观察结果，逆矩阵中的数值巨大，约为 10 的 14 次方。


用这个逆矩阵计算权重时，重复特征对应的权重也会非常大。独立的第一个特征权重正常，为 0.62；第二个和第三个特征却得到约 340 万和 -340 万的权重。


因此，特征矩阵中存在重复列或近似重复列时，就可能遇到这个问题。

## 一个更小的例子

用更小的矩阵说明上述情况。这个矩阵也有一列与另一列重复：

```python
XTX = [
    [1, 2, 2],
    [2, 1, 1],
    [2, 1, 1],
]
```

尝试求逆时，NumPy 会报错：矩阵是奇异矩阵，无法计算逆矩阵：


现在像之前一样添加一点微小噪声：

```python
XTX = [
    [1, 2, 2],
    [2, 1, 1.0000001],
    [2, 1.0000001, 1],
]
```

逆矩阵现在存在，但其中的数值约为 500 万。接下来解决这个问题。

## 用正则化控制权重

解决方法是在矩阵对角线上加一个小数，例如 0.01。这样仍能求出逆矩阵，而且其中的数值更可控。加到对角线上的数越大，对权重的约束通常越强。

这种做法通过修改对角线，缓解列之间的线性依赖问题。

为了给对角线加上一个数，使用单位矩阵。`np.eye(3)` 是 3×3 单位矩阵，对角线上的值均为 1。将它加到原矩阵上，对角线就各增加 1：

```python
XTX + np.eye(3)
```


如果只想加一个小数，先将单位矩阵乘以该数：

```python
XTX = XTX + 0.01 * np.eye(3)
```

这种控制权重的方法称为正则化，即约束权重，使它们不会增长得过大。

加入的数实际上是一个参数。对角线上加入的数越大，对 `XᵀX` 求逆时的数值通常越稳定。正则化的强度因此成为模型的一个参数。

## 带正则化的训练函数

现在回到线性回归训练函数，稍作修改。新函数命名为 `train_linear_regression_reg`，增加一个参数 `r`，表示正则化强度：

```python
def train_linear_regression_reg(X, y, r=0.001):
    ones = np.ones(X.shape[0])
    X = np.column_stack([ones, X])

    XTX = X.T.dot(X)
    XTX = XTX + r * np.eye(XTX.shape[0])

    XTX_inv = np.linalg.inv(XTX)
    w_full = XTX_inv.dot(X.T).dot(y)

    return w_full[0], w_full[1:]
```

除了新增一行，其他步骤不变：计算格拉姆矩阵后，在主对角线上加上 `r`。


取上一节的代码，将训练函数替换为新函数，并设置 `r=0.01`：

```python
X_train = prepare_X(df_train)
w0, w = train_linear_regression_reg(X_train, y_train, r=0.01)

X_val = prepare_X(df_val)
y_pred = w0 + X_val.dot(w)
rmse(y_val, y_pred)
```

结果不仅远好于未正则化版本的 41，也优于添加所有类别变量之前的结果：

```
0.4608208286209523
```


通过给对角线加一个数，我们控制了权重并对模型进行了正则化。但 `r` 是参数：设得太大，模型可能变差；设为 0，则回到普通线性回归。因此需要寻找最佳的 `r`，这就是[下一节](14-tuning-model_chi.md)的内容。

## 笔记

如果特征矩阵存在重复列，或某列可表示为其他列的线性组合，则相应的格拉姆矩阵不可逆。但如果重复列中的某些值略有差异，数值计算中可能不会直接报出这个错误。

此时应用正规方程，重复列对应的权重可能非常大，从而降低模型表现。一种解决方法是在矩阵的对角线上加一个小数，这就是正则化。

这项技术通过给对角线添加小数，缓解列之间的线性依赖。正则化强度是模型的超参数。应用正则化后，模型表现得到了改善。

## 补充说明
### 线性组合

视频中提到了*线性组合*，但没有解释其含义。如果感兴趣，可以阅读下面的说明：

* 如果矩阵中的某一列可以表示为其他列乘以系数后相加的结果，该列就是其他列的线性组合。
* 最简单的例子是某一列与另一列完全重复。
* 另一个例子：假设有三列 `a`、`b`、`c`。如果 `c = 0.2 * a + 0.5 * b`，那么 `c` 就是 `a` 和 `b` 的线性组合。
* 更严格的定义：https://en.wikipedia.org/wiki/Linear_combination

### 岭回归
本节采用的正则化方法，即在格拉姆矩阵对角线上添加一个因子，属于岭回归（Ridge Regression）。更多解释可阅读这篇 [DataTalks.Club 文章](https://datatalks.club/blog/regularization-in-regression.html)。
